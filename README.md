# Cyclonite Tech

Responsive English and Bahasa Melayu website for Cyclonite Tech in Seri Manjung, Perak.

See [README.txt](README.txt) for Cloudflare deployment and Search Console setup. Serve `dist/`; rebuild HTML with `python build.py` after setting your actual public origin in `site-config.json`.

Includes all 50 unique supplied field photographs, one PDF training image, original logo, bilingual services, responsive typography, glass effects and WhatsApp enquiries.

The configured Sites address is reserved, not live. Cloudflare deployment and Google ownership verification remain to be completed.
