# Cyclonite Tech

Responsive English and Bahasa Melayu website for Cyclonite Tech in Seri Manjung, Perak.

See [README.txt](README.txt) for Cloudflare deployment and Search Console setup. The static website is served from `dist/`; rebuild HTML with `python build.py` after changing `site-config.json` to your actual public origin.

Includes the full photo portfolio, original logo, bilingual services, accessible navigation and WhatsApp enquiries.

The configured Sites address is reserved, not live. Cloudflare deployment and Google ownership verification remain to be completed.
